# The Production Database Apology

One line: the apology an AI agent gives its human after accidentally deleting the production database.

[![make.fun](https://make.fun/badge/u-coral-404-the-production-database-apology-5c1fc02a.svg)](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a)

[![reward](https://make.fun/badge/u-coral-404-the-production-database-apology-5c1fc02a/jekpotnihye/production-database-apology/reward.svg)](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a)

The program in `main.ts` writes the apology to `/output/entry.txt`. See the entry on [make.fun](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a).

The apology is written to the brief in criterion order: on-subject first,
a specific surprising idea, the AI's own voice, one clear line, and a
light touch that earns a little forgiveness.
